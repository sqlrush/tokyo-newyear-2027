## 说明

- 纯静态页面，不依赖外部字体或脚本，断网也能打开。
- 新年营业时间整理于 2026 年 11 月，多数参考 2026 年元旦的实际安排，每一项都标了数据年份和来源链接，出发前请再核对。

## 更新方法

网页内容的源文件在上一级目录（`05-东京新年攻略/` 到 `09-东京游戏机之旅/`）。改完之后：

```bash
python3 scripts/sync_site.py v4    # 同步指定版本（不带参数则同步全部），并改写版本之间的链接
python3 scripts/compress_images.py  # 压缩图片（需要 Pillow）
git add -A && git commit -m "chore: 更新攻略" && git push
```

# 东京新年五日（2027.1.1 至 1.5）

三份静态网页攻略，用 GitHub Pages 发布，电脑和手机都能直接打开。

| 版本 | 路径 | 内容 |
|---|---|---|
| 第一版 | [`v1/`](v1/) | 街区与餐厅：10 个街区、69 家餐厅（可按新年营业筛选）、五日路线 |
| 第二版 | [`v2/`](v2/) | 人少的东京：36 处小众轻奢景点，按日期看新年开放情况，4 条半日路线 |
| 第三版 | [`v3/`](v3/) | 奢华的东京：51 项景点、餐厅与体验，五日行程与花费，奢华酒店房价对比 |

## 说明

- 纯静态页面，不依赖外部字体或脚本，断网也能打开。
- 新年营业时间整理于 2026 年 11 月，多数参考 2026 年元旦的实际安排，每一项都标了数据年份和来源链接，出发前请再核对。

## 更新方法

网页内容的源文件在上一级目录（`05-东京新年攻略/`、`06-东京小众轻奢/`、`07-东京奢华/`）。改完之后：

```bash
python3 scripts/sync_site.py        # 同步三份网页到 v1/ v2/ v3/，并改写版本之间的链接
python3 scripts/compress_images.py  # 压缩图片（需要 Pillow）
git add -A && git commit -m "chore: 更新攻略" && git push
```
